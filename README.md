# My Tracker - NoFap Mode

A fully offline Expo React Native app focused on NoFap discipline tracking.

## Stack
- React Native (Expo)
- AsyncStorage only (no backend/cloud/auth)
- Dark-mode-first minimal UI

## Run
```bash
npm install
npm run start
```

## Features
- Home screen with date, current streak, longest streak, and motivational quote
- One-tap daily clean check-in and relapse marker with confirmation popup
- GitHub-style yearly contribution heatmap (clean/relapse/no-data colors)
- Stats page with totals, success percentage, and monthly breakdown
- Optional Hard Mode with discipline messaging
- All data persisted locally in AsyncStorage
